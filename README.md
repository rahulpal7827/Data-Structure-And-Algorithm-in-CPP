# 🧠 Data Structures & Algorithms in C++

> A comprehensive collection of DSA concepts and problem solutions implemented in C++, with practice problems from **LeetCode**, **Codeforces**, and **GeeksForGeeks**.

---

## 📁 Repository Structure

```
Data-Structure-And-Algorithm-in-CPP/
├── Array/                  # Array problems and techniques
├── DecimalAndBinary/       # Number system conversions & bit manipulation
├── Searching and Sorting/  # Linear search, binary search, bubble/merge/quick sort, etc.
├── funtion/                # Function-based problems and recursion
├── switchcases/            # Switch-case logic and control flow problems
└── README.md
```

---

## 🚀 Topics Covered

| Topic | Concepts |
|---|---|
| **Arrays** | Traversal, Prefix Sum, Sliding Window, Two Pointers |
| **Decimal & Binary** | Base conversions, Bitwise operations |
| **Searching & Sorting** | Linear/Binary Search, Bubble/Selection/Merge/Quick Sort |
| **Functions** | Recursion, Pass by value/reference, Default arguments |
| **Switch Cases** | Menu-driven programs, Pattern matching |

## 🛠️ Getting Started

### Prerequisites
- A C++ compiler: `g++` (GCC) or `clang++`
- C++17 or later recommended

### Compile & Run

```bash
# Clone the repository
git clone https://github.com/rahulpal7827/Data-Structure-And-Algorithm-in-CPP.git
cd Data-Structure-And-Algorithm-in-CPP

# Compile any file
g++ -std=c++17 -o output Array/your_file.cpp

# Run
./output
```
